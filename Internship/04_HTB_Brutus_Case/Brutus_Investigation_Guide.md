# HTB Sherlocks — Brutus
Use the official Brutus archive from your own HTB account. Preserve the original archive and calculate its SHA-256 before extraction.
Workflow: record acquisition details -> hash archive -> extract working copy -> identify logs/timezone -> parse failed/successful authentication -> identify suspicious IPs/users/sessions/privilege changes -> correlate events -> build timeline -> map supported behavior to ATT&CK -> cite raw log evidence -> report limitations.
The Brutus investigation findings are documented in HTB_Brutus_DFIR_Investigation_Report.docx and supported by the available evidence screenshots. The original Brutus archive and raw evidence files are not included in this portfolio package. Findings should be interpreted within the scope and limitations stated in the investigation report.
